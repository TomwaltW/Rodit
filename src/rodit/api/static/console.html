话术助手（模式 C）

登录

店长、商家、复核人员用自己的令牌登录；客服请用话术助手。令牌只保存在本标签页（sessionStorage），关闭标签页即失效，不会出现在网址里。

知识

店长只能查看；新增、修改、审核和下线由商家操作。

要补的知识

候选知识（待审核）

客服「编辑后发送」的回答会生成候选知识，商家审核通过后才用于回答（§5.8）。

新增 FAQ

写买家常问的说法，如「发什么快递」。

保存后直接上线；保存时会按回答时的质检规则检查，有问题会提醒（不拦截保存）。

FAQ

店铺政策

店长只能查看；政策由商家修改。

回答时店铺政策优先于商品详情和 FAQ（§5.2.1），改动即时生效。整份附录 C 问卷可以在话术助手页的「店铺数据」里填写。

商品

店长只能查看；商品卡片由商家填写，同步由商家发起。

同步只更新平台字段（标题、属性、SKU、详情，含详情图识别的文字），商家填写的字段不动；已下架和平台上没有了的商品只提示、不删除（§5.2.3）。

店铺设置

店长只能查看；设置由商家修改。

平台默认 → 类目默认 → 店铺设置，下层覆盖上层（§9.3）。「恢复默认」删掉店铺设置，回到平台 / 类目默认。判断阈值由我们统一校准，不开放修改。

上线节奏

影子模式（生成不展示，事后对比）→ 智能辅助（展示推荐，客服决定）→ 按类型评估半自动 / 全自动（§13.4）。这里只有计数和分数，没有对话内容。

切换阶段

每周复核

复核列表会显示推荐原文和买家问题（已打码），每次查看都会记录访问日志（§9.2）。只在需要复核时加载。

默认上一个完整周（东八区周一 0 点起）。抽样按问题类型分层；重复抽样只补不换。
