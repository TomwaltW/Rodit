使用前须知：只能在本店已与我们签署《个人信息委托处理协议》后使用（方案 §8.1，建议法务确认）
  • 只粘贴买家的问题本身，不要粘贴昵称、手机号、收件地址、订单号。粘贴的文字进入系统时先做个人信息最小化（手机号、地址等打码），之后才会调用大模型（§5.3）。
  • 本工具不做任何自动抓取；推荐由你确认后自己复制回平台发给买家。模式 C 没有平台数据，查不到订单、物流、售后进度。
